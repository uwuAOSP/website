这些功能用于按应用管理传感器访问、剪贴板和跨应用跳转。

## 应用传感器访问

打开设置中的“应用传感器访问”，选择需要管理的应用：

| 策略 | 效果 |
| --- | --- |
| 全部允许 | 不增加额外限制 |
| 打开后禁止 6 秒 | 每次进入应用页面时，暂时阻止传感器访问 |
| 永久禁止 | 一直阻止，直到修改策略 |

这项设置可以限制加速度计、陀螺仪等传感器。

> [!TIP] 摇一摇或运动功能无法使用
> 将该应用的传感器访问恢复为“全部允许”。

## 应用剪贴板权限

打开“应用剪贴板权限”，为应用选择允许、询问或拒绝。规则同时影响读取和写入剪贴板。

选择“询问”后，应用访问剪贴板时会弹出确认窗口：

- 不勾选“写入永久规则”：拒绝只影响这次请求；允许会给应用一小段临时访问时间。
- 勾选“写入永久规则”：保存为该应用的长期规则。
- 关闭窗口或返回：拒绝这次请求，不保存规则。

## 应用跳转权限

用来管理“浏览器打开购物 App”等跨应用跳转。在“应用跳转权限”中开启保护后，可以按以下方式设置：

| 规则 | 适合的情况 |
| --- | --- |
| 来源应用 | 不希望某个应用随意打开其他应用 |
| 目标应用 | 不希望某个应用被其他应用打开 |
| 应用配对 | 只管理某个应用到另一个应用的跳转 |

每条规则可以选择允许、询问或阻止。应用配对规则优先于来源或目标规则。

询问窗口会显示来源和目标应用。勾选“记住我的选择”后，结果保存为这一对应用的规则；
返回或点按窗口外则取消这次跳转。

关闭保护会保留已有规则。
