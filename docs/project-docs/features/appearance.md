## 桌面一览

主屏幕第一屏顶部的一览区域可以显示日期、天气、闹钟、计时器和媒体信息。
播放音乐时，可以横向切换状态页和媒体页。

在主屏幕设置中：

- “显示一览”控制这块区域是否显示。
- “使用 Smartspacer”允许已安装并获得授权的 Smartspacer 提供卡片。

> [!NOTE] 一览来源
> Smartspacer 不可用时，系统会切回内置一览。

## 系统小图标

进入 **uwuAOSP Plus! > 界面设置 > 系统小图标**，选择默认或 PUI 风格。

> [!TIP] 图标还没更新
> 重新打开对应界面即可看到新的图标。

PUI 图标来自 **PUI Theme For Stock Android v17.0.218**，原作者为 **天伞桜**。

## 状态栏歌词

进入 **uwuAOSP Plus! > 状态栏歌词**，打开开关，并将提供歌词的音乐应用加入白名单。

可以选择两种位置：

- **覆盖起始侧**：歌词暂时占用状态栏左侧区域。
- **时钟右侧**：保留时钟；歌词出现时，通知应用图标暂时隐藏。

可以按需显示翻译和应用图标。触摸歌词可以暂时隐藏它。
歌词和翻译由音乐应用提供。

## 自定义字体

可以使用自己的字体替换系统默认字体。
