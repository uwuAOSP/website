Prism 可以从当前屏幕框选内容，识别文字或保存图片。

1. 进入 **uwuAOSP Plus! > Prism**，启用“三指上滑”。
2. 解锁屏幕后，在需要提取内容的页面三指上滑。
3. 创建选区，并按需移动或调整大小。
4. 选择复制、保存或导出。

> [!NOTE] 导出格式
> 文字选区可以导出 TXT 或 PDF；图片选区可以保存为图片或导出 PDF。
