进入 **设置 > 系统 > 软件更新**。

> [!IMPORTANT] 更新前
> 备份重要资料，保持足够电量，并使用当前设备维护者提供的更新包。

## 检查更新

点按检查更新。更新器可能提供两种结果：

- **官方版本信息**：显示 uwuAOSP 的最新版本，对应设备的构建由维护者提供。
- **设备 OTA 更新**：维护者已配置更新源时，可以在更新器中下载和安装对应更新。

## 安装本地更新包

1. 获取维护者提供的 OTA ZIP，保留 ZIP 格式。
2. 点按页面右上角的文件导入按钮，选择 ZIP。
3. 等待导入完成。
4. 点按安装，并按照页面提示继续。

## 安装与重启

A/B 设备通常在后台完成安装，安装结束后再由你选择重新启动。
使用 Recovery 安装的设备会进入恢复环境，需使用维护者要求的兼容 Recovery。

> [!WARNING] 安装期间
> 不要强制关机。等更新器提示重启后再重启。
